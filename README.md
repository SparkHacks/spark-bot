## SparkHacks Bot
Discord bot that automates SparkHacks Discord servers setup and day-to-day management, handling creation of both the organizing team's server and the hackers' event server, welcome messages for new members, logging of edited and deleted messages, and much more.

### Requires
- [pyenv](https://github.com/pyenv/pyenv)
- [pre-commit](https://pre-commit.com/)

### Getting Started
```bash
git clone git@github.com:SparkHacks/spark-bot.git
cd spark-bot
pyenv install
pip install -r requirements.txt
pre-commit install
```

### Running Locally
```bash
python main.py
```
